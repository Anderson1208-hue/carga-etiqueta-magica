# Architecture rules
- OK Entrega scheduled validation uses a dedicated authenticated consultation endpoint, never the enqueue/transmission job; gate dispatch with the existing RJ business-day calendar to avoid holiday calls, select routing dates through the current Brasília day and page deterministically, preserving original occurrence IDs.
- OK Entrega rejected-photo corrections stage a unique storage object without changing the operational POD, require server-validated approved-operator access and a conditional rejected-row reservation, and transmit only on explicit confirmation; preserve historical images and portal responses and never automatically retry a corrected submission.

- OK Entrega portal consultation is isolated from image transmission; authenticate approved operators and return only allowlisted business data, never portal HTML or authentication responses, to prevent credential leakage and accidental retransmission.
- OK Entrega portal parsing uses a tested shared parser for document-link IDs and validation-result arrays; mirror the portal's actual fields rather than assuming HTML quoting or scalar statuses.
- OK Entrega validation updates verify the original transmitted occurrence belongs to the document and authorized routing date, then read the latest uniquely dated delivery occurrence including manual portal corrections; retain the original transmission ID and never infer approval from unknown or ambiguous results.

- OK Entrega date consultation uses the vehicle routing date and fetches queue results for those invoices independently of the recent technical-history limit; historical statuses must not disappear because of that limit.

- Keep operator navigation grouped in lateral flyouts within the existing desktop Sidebar, retaining existing route targets and access-hook filters; this reduces menu clutter without changing business workflows or the driver application.
- In RLS policies always wrap no-argument helper checks as `(SELECT public.is_admin())` / `(SELECT public.is_active_operator())`; bare calls run once per row and saturated the database (outages Oct/2026).
- Geocode-cache reads require active profiles in RLS; geocoding endpoints using service credentials must validate the caller and protected profile approval through the shared operator guard, because service credentials bypass RLS.- OK Entrega transmission has its own 15-minute queue-drain schedule calling the send job; never repurpose it for validation consultation, because stuck items are only released when the send job runs.
- Cacau Show (IBAC/IBAE) portal consultation remains read-only; explicitly confirmed rejected-photo replacement uses ibac-corrigir-foto outside the automatic queue, with per-note reservation, current portal validation, verified private remote-image backup and durable phase history; recovery never repeats deletion and never infers approval from upload success.
- MO image lookup joins the uniquely keyed list row to detail by image OID and documentoIndustria.chaveDoc; retain list validation because the image detail omits it, and reject changed identifiers before replacement.
- MO corrective upload sends the verified complete image-detail DTO with only base64/name replaced, matching its portal UI; pace portal calls and confirm exact stored image before completion, because a minimal DTO can return success without persisting the photo.
